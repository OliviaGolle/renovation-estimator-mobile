avec un champ "image" (ex: "image": "data/images/pm1.jpg"). Voir le README pour les détails.

ATTENTION : ce dossier "mobile" est publié publiquement sur GitHub Pages. N'y mettez pas
de photos protégées par le droit d'auteur (ex: photos Leroy Merlin) sans autorisation.
